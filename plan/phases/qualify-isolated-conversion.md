# Qualify isolated conversion

## Goal

Support configuration-driven operation and qualify Drawbridge on hardware-isolated, networkless Linux arm64. The owner authorized necessary changes to the document conversion stack and owned dependencies for that capability. This phase changes Drawbridge only. Preserve public readers, original bytes, provenance, privacy policy and the independently installed PDF-engine boundary.

## Scope

- Add explicit Conric executable, limit, runtime path and conversion options. Preserve standalone options and keep explicit jobs independent of ambient profile, home and dotenv discovery.
- Add bounded Bedrock Converse for structure, image description and transcript refinement. A configured command route requires explicit brokered egress, uses exactly one transport, and inherits only caller-listed descriptors outside standard I/O. Use fakes and synthetic data for provider paths.
- Report unavailable Vellric as operational, describe live OCR skips accurately, and keep native PPTX imports within the existing seccomp boundary with single-threaded numerical runtimes.
- Bound OCR raster work with a one-page default, an explicit page-worker ceiling, and one lossless temporary rotation at a time. Preserve complete source and citation validation. Keep finite configurable complete-job guards and a bounded manifest read until the entire job can be consumed incrementally. Exercise the successful job boundary with a fake CLI and independently validated artifacts, including the final terminal-to-manifest count check.
- Prepare opaque Quillric configuration paths without changing its pin or enabling an unconfirmed integration. Build and qualify offline Linux aarch64 installation artifacts and local conversions. The phase authorizes no tags, releases or paid/provider calls.

### Compatibility and resource bounds

Under AGENTS.md hard rule 2, this phase explicitly removes the bare `kind: command` endpoint without a compatibility path. Its schema admitted profiles for a transport without a matching runtime implementation. Automatically reinterpreting such profiles as the new Bedrock broker could grant egress that the original profile did not authorize. Configure `kind: bedrock-converse`, `transport: command` and `allow_brokered: true` to use the new protocol. The minor version bump records the break.

Vellric stderr is consumed incrementally. A total-byte cutoff on a long stream of well-formed progress could interrupt a valid long job even though its processing state remains bounded. A 128 KiB incomplete-line guard bounds the retained stderr, the stdout protocol has its own cap, and the document deadline still applies.

## Acceptance

Inspect the configuration-only execution path with explicit output and work locations. Exercise configuration rejection before document reads, policy refusal, descriptor admission, process limits, categorical errors, bounded images and zero transport fallback. Verify native PPTX startup with numerical libraries importable on Linux aarch64 and prove installed text, office, image OCR and PDF conversion with an independent Vellric through the documented qualification procedure. Retain exact candidate evidence and the observed runtime binaries and locale in private custody.

Run focused repository tests before independent code review, end implementation qualification with `./bin/test --changed-from '@{upstream}'`, and run one `./bin/check all` on the handoff tree after tracked bookkeeping. Record the actual independent plan and code reviews, gates and custody through the repository's kickoff procedure.

User Demo: Convert a public or synthetic document with explicit files and compare the fidelity mirror and the separate stage result. Replace the fake broker's success reply with a categorical failure, rerun with a fresh cache, and confirm the fidelity mirror is still readable and the requested stage reports pending. Review the output and work directory placement.
