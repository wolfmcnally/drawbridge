Before sealing a Drawbridge phase that changes a pinned tool, compare every receiving tool against the actual qualified live source using the production admission predicate. Advice can execute with an older preserved watcher and product tests can pass while canonical phase admission still refuses that bundle. The observed close sealed private acceptance and appended END before admission refused; its phase-completion event was absent. Preserve that partial outcome byte-for-byte and use a supported fresh current-tool continuation with strict original advice carry and unchanged consumed budgets. Do not repin a sealed snapshot, manually publish the refused event, or call the prior close a completed phase. This is a local lesson from this release; no upstream change is proposed.
