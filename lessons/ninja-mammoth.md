Run bounded policy, documentation and downstream package prerequisite checks under the exact planned gate environment. Ambient policy/docs passed, but a restricted external launcher omitted already installed documentation executables and the full gate stopped after its tests passed. Adding only the verified tool location restored the exact-environment policy check; executable versions, offline dependency/build-backend resolution and installed-engine prerequisites were then checked before another expensive gate. A successful test component never supplies a passing full receipt.
