# Licensing and the standalone boundary

Drawbridge 0.2.0 is MIT; LICENSE and NOTICE accompany its project artifacts. Its runtime wheel contains Python source/notices and separately installs permissive dependencies, including public MIT Conric 0.1.0 at its exact recorded Git commit. PDF parsing/rendering/OCR/native typography belong to independently installed **Vellric**, AGPL-3.0-only, through complete document jobs. This candidate targets public regular Vellric v0.2.4 at commit `8b410165a52b246e72dc2ac326ce9e289c80aa43`, using the release wheel and matching source archive pinned by artifact hashes. Cloud-vision human acceptance and Windows desktop acceptance remain open upstream. Drawbridge imports/installs neither Vellric nor PyMuPDF in its runtime. Pillow owns non-PDF images.

PyMuPDF remains a development-only fixture/lock-test dependency. Existing external consumers that own native engine objects retain their own obligations and use the real PDF_LOCK/pdf_locked exports until migrated. Quillric is an optional audio distribution with its own notices, compatibility import namespace and provider requirements.

The source archive includes unmodified public fixtures. Their CC-BY-SA-4.0/IETF grants, original sources/hashes and attribution remain in tests/fixtures/MANIFEST.md, NOTICE and LICENSES/CC-BY-SA-4.0.txt. MIT does not overwrite those grants. The full CC text is retained from [SPDX primary license data](https://github.com/spdx/license-list-data/blob/main/text/CC-BY-SA-4.0.txt).

As of 2026-10-29, the page-citation integration targets the public Vellric 0.2.4 release described above. This working-tree change is not a new published Drawbridge release; integration authority does not itself authorize public release/push. Cloud-vision qualification is not claimed. Matching wheel/source/lock/build material and notices stay together. The retained distribution metadata uses an exact Git dependency rather than a package-index-only dependency set. Live consumer upgrades remain separately authorized. The preserved briefs/plan/tests explain design and methodology; they remain in the repository/source archive.
